# api/_loadEnv.ts

## Что делает файл

Единоразово загружает серверные env из `.env.local` и `.env`.

## Импорты и зависимости

1. `dotenv` используется для чтения переменных окружения из локальных env-файлов.

## Экспорты и контракты

1. `ensureServerEnvLoaded()` — безопасная одноразовая загрузка env для server/api entrypoints.

## Нетривиальная логика

1. Повторная загрузка блокируется через `isEnvLoaded`.
2. В Vercel включается `quiet`-режим, чтобы `dotenv` не засорял serverless-логи служебными сообщениями.

## Где используется

1. `api/_firebaseAdmin.ts`
2. `api/_mongodb.ts`
