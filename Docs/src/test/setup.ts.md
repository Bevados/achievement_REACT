# src/test/setup.ts

## Что делает файл

Это глобальный setup-файл для Vitest + Testing Library.
Он подключает `jest-dom` матчеры и очищает виртуальный DOM после каждого теста.
Цель файла - обеспечить единое и чистое тестовое окружение для всех test/spec файлов.

## Импорты и зависимости

1. `@testing-library/jest-dom/vitest` - добавляет дополнительные матчеры (`toBeInTheDocument` и др.) для Vitest.
2. `vitest` (`afterEach`) - lifecycle hook после каждого теста.
3. `@testing-library/react` (`cleanup`) - удаляет смонтированные компоненты из DOM между тестами.

## Экспорты и контракты

1. Экспортов нет.
2. Контракт файла - side effects при инициализации тестового раннера.
3. Инварианты:
4. После каждого теста вызывается `cleanup()`.
5. Любой тест в проекте может использовать матчеры jest-dom без локального импорта.

## Нетривиальная логика

1. Нетривиальной бизнес-логики нет; ключевая ценность в предотвращении flaky-тестов из-за утечки DOM между кейсами.
2. Cleanup на уровне setup надежнее, чем ручной cleanup в каждом тестовом файле.

## Где используется

1. Подключается глобально через `vite.config.ts` -> `test.setupFiles: './src/test/setup.ts'`.
2. Применяется ко всем тестам в `src/**/*.test.ts*`.
