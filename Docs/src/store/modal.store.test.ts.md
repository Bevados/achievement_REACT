# src/store/modal.store.test.ts

## Что делает файл

Файл проверяет базовые переходы состояния `useModalStore`.
Тесты подтверждают корректность операций открытия, переключения и закрытия модалки.

## Импорты и зависимости

1. `vitest` - описание и assertions.
2. `./modal.store` (`useModalStore`) - тестируемый Zustand-store.

## Экспорты и контракты

1. Экспортов нет.
2. Контракты, которые проверяются:
3. `openModal('login')` ставит `isOpen=true` и `activeModal='login'`.
4. `switchModal('register')` меняет только активный контент, сохраняя окно открытым.
5. `closeModal()` возвращает store к начальному состоянию.

## Нетривиальная логика

1. Перед каждым тестом store вручную сбрасывается через `setState`, чтобы исключить зависимость между кейсами.
2. Тесты работают напрямую со state API store (`getState`), без рендера UI.

## Где используется

1. Запускается Vitest через `npm run test`.
2. Тестирует `src/store/modal.store.ts`.
3. Общий setup подключается через `src/test/setup.ts`.
