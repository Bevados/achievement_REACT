# src/pages/ExamplesPage/ExamplesPage.tsx

## Что делает файл

Файл реализует публичную страницу примеров коллекций (`/examples`).
Логика списка (фильтры, пагинация, URL-sync и загрузка) вынесена в общий хук, а UI фильтров/пагинации вынесен в общие компоненты.
Страница выступает как тонкая оболочка для публичного источника данных (`/api/examples/collections`) и текстов публичного контекста.

## Импорты и зависимости

1. `src/api/collections.api.ts` (`getPublicCollections`) - источник публичных данных.
2. `src/hooks/useCollectionsListController.ts` - общий контроллер списка коллекций.
3. `src/components/Collections/CollectionsFilters.tsx` - общий UI-блок фильтров.
4. `src/components/Collections/CollectionsGrid.tsx` - общий UI-блок сетки карточек.
5. `src/components/Collections/CollectionsPagination.tsx` - общий UI-блок пагинации.

## Экспорты и контракты

1. Экспортируется default-компонент `ExamplesPage`.
2. Компонент не принимает пропсы.
3. Данные загружаются через `getPublicCollections` и общий контроллер `useCollectionsListController`.
4. Локально страница не хранит собственную бизнес-логику фильтров/URL-sync, а получает готовый state+actions из хука.

## Нетривиальная логика

1. Повторяемая логика списка больше не дублируется в странице, а переиспользуется из общего хука.
2. Ветка `loading/error/empty/success` сохранена, но UI фильтров и пагинации делегирован отдельным переиспользуемым компонентам.
3. Публичная страница теперь отличается от private-страницы главным образом источником данных и текстами, а не структурой логики.

## Где используется

1. `src/App.tsx` - маршрут `/examples` для неавторизованных пользователей.
