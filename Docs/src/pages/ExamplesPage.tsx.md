# src/pages/ExamplesPage.tsx

## Что делает файл

Файл задает публичную заготовку страницы примеров коллекций (`/examples`).
Страница нужна для сохранения целостности public-навигации и подготовки к подключению API examples.

## Импорты и зависимости

1. Явные импорты отсутствуют.
2. Компонент рендерит статический UI и не зависит от store.

## Экспорты и контракты

1. Экспортируется default-компонент `ExamplesPage`.
2. Компонент не принимает пропсы.
3. Контракт текущей версии:
4. Показывает заголовок раздела и 6 demo-заглушек публичных коллекций.

## Нетривиальная логика

1. Заглушки рендерятся через `Array.from({ length: 6 })`, чтобы оставить компактный и расширяемый шаблон для будущей API-подгрузки.
2. Раздел остается guest-only на уровне guard в `src/App.tsx`.

## Где используется

1. `src/App.tsx` - маршрут `/examples` для неавторизованных пользователей.
