# src/pages/HomePage/HomePage.tsx

## Что делает файл

Файл реализует гостевую главную страницу приложения.
Страница содержит Hero-блок с CTA на создание коллекции, блок преимуществ и preview-заглушки карточек.

## Импорты и зависимости

1. `react-router-dom` (`Link`) - SPA-навигация на страницу примеров без перезагрузки документа.
2. `src/config/home.config.ts` - источник контентных данных для блоков benefits и preview.
3. Входной callback приходит через пропсы от `src/App.tsx`.

## Экспорты и контракты

1. Экспортируется default-компонент `HomePage`.
2. Пропсы компонента:
3. `onCreateCollection: () => void` - вызывается при клике на primary CTA.
4. Инварианты:
5. Hero CTA обязан вызывать `onCreateCollection` и не должен выполнять авторизацию напрямую.
6. Правая Hero-визуализация скрывается на mobile (`hidden lg:block`).
7. Блок превью рендерит статические placeholders без обращения к API.
8. Secondary CTA "Посмотреть примеры" ведет на route `/examples` через `Link`.

## Нетривиальная логика

1. Страница сознательно разделена на три секции (Hero, benefits, preview), чтобы легко масштабировать каждую независимо на следующих шагах.
2. Декоративная правая панель помечена `data-testid`, чтобы в тестах можно было проверить mobile/desktop классы без snapshot-шаблонов.
3. Контентные массивы вынесены в конфиг, чтобы упростить поддержку текста и не смешивать данные со структурой JSX.
4. Для primary/secondary CTA используется `inline-flex + justify-center + text-center`, чтобы текст оставался центрированным при расширении кнопки на мобильной ширине.

## Где используется

1. `src/App.tsx` - рендерит HomePage на маршруте `/` только для гостей.
2. `src/pages/HomePage/HomePage.test.tsx` - проверяет вызов CTA callback и структуру preview-блока.
