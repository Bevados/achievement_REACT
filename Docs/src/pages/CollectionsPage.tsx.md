# src/pages/CollectionsPage.tsx

## Что делает файл

Файл задает каркас private-страницы "Мои коллекции".
На текущем шаге это заготовка маршрута `/collections`, доступного только авторизованному пользователю.

## Импорты и зависимости

1. Явные импорты отсутствуют.
2. Компонент не зависит от API, store и роутера напрямую.

## Экспорты и контракты

1. Экспортируется default-компонент `CollectionsPage`.
2. Компонент не принимает пропсы.
3. Контракт текущей версии:
4. Отображает private-заголовок и технический текст о следующем шаге интеграции.

## Нетривиальная логика

1. Логика минимальна: компонент специально оставлен простым, чтобы отделить задачу route-guard от полной CRUD-реализации.
2. Это позволяет уже сейчас валидировать redirect-policy `/ -> /collections` для авторизованного пользователя.

## Где используется

1. `src/App.tsx` - рендерит страницу на маршруте `/collections` при `isAuthenticated=true`.
