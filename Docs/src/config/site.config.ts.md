# src/config/site.config.ts

## Что делает файл

Файл хранит централизованную конфигурацию сайта: заголовок/описание и наборы пунктов навигации для гостя и авторизованного пользователя.
Это избавляет от хардкода меню прямо в компонентах.

## Импорты и зависимости

1. Импорты отсутствуют.
2. Файл содержит только объект конфигурации.

## Экспорты и контракты

1. Экспортируется объект `siteConfig`.
2. Ключи объекта:
3. `title`, `description`.
4. `navItemsPublic` - пункты меню для гостей.
5. `navItemsPrivate` - пункты меню для авторизованных.
6. Каждый пункт навигации имеет форму `{ label: string, path: string }`.
7. Инварианты:
8. `path` должен соответствовать существующему или планируемому маршруту.
9. Label/path для public и private меню должны быть согласованы с UX-логикой Header.

## Нетривиальная логика

1. Исполняемой логики нет, но есть архитектурное правило: источник правды для навигации должен быть один.
2. Наличие двух массивов (`navItemsPublic` и `navItemsPrivate`) упрощает условный рендер в Header.
3. В `navItemsPrivate` маршрут `/profile` пока закомментирован, что отражает текущий scope проекта.

## Где используется

1. `src/components/Header/Header.tsx` - выбирает `navItemsPublic` или `navItemsPrivate` в зависимости от состояния авторизации.
2. Косвенно влияет на навигацию, отображаемую в `src/App.tsx` через рендер Header.
