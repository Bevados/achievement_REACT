# src/config/home.config.ts

## Что делает файл

Файл хранит контентные данные для гостевой главной страницы: список преимуществ и названия preview-карточек.
Это отделяет текстовый контент от JSX-разметки компонента HomePage.

## Импорты и зависимости

1. Внешние импорты отсутствуют.
2. Файл содержит только тип и экспортируемые константы.

## Экспорты и контракты

1. Экспортируется интерфейс `HomeBenefit` с полями `title` и `description`.
2. Экспортируется массив `homeBenefits: HomeBenefit[]`.
3. Экспортируется массив `homePreviewCards: string[]`.
4. Инварианты:
5. `homeBenefits` должен содержать короткий title и читаемое описание для карточки преимущества.
6. `homePreviewCards` используется как список подписей для demo-превью и не зависит от backend.

## Нетривиальная логика

1. Исполняемой логики нет, но есть архитектурная роль: хранить контент отдельно, чтобы обновлять тексты без редактирования структуры компонента.
2. Такой подход упрощает дальнейшую локализацию и переиспользование данных на других публичных страницах.

## Где используется

1. `src/pages/HomePage.tsx` - рендерит секции benefits и preview по данным из этого файла.
