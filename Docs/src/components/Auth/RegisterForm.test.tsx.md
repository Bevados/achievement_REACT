# src/components/Auth/RegisterForm.test.tsx

## Что делает файл

Файл тестирует форму регистрации `RegisterForm`:

1. Кросс-полевую валидацию паролей.
2. Корректный вызов `register(email, password, nickname)`.
3. Отображение сообщений об ошибке из auth-store.

## Импорты и зависимости

1. `vitest` + Testing Library + `user-event` - проверка пользовательских сценариев формы.
2. `./RegisterForm` - тестируемый компонент.
3. Мок `../../store/auth.store` - управляемый селектор Zustand для изоляции формы от реального store.

## Экспорты и контракты

1. Экспортов нет.
2. Контракт, покрытый тестами:
3. При несовпадении `password` и `confirmPassword` submit блокируется.
4. При валидном вводе вызывается `register` с ожидаемым порядком аргументов.
5. Ошибка из `auth.store.error` отображается в UI.

## Нетривиальная логика

1. Проверяется именно business-critical порядок аргументов `register(email, password, nickname)`.
2. Асинхронный submit проверяется через `waitFor`, чтобы избежать гонок с ререндером формы.
3. Плейсхолдеры используются как стабильные селекторы инпутов, что делает тесты менее хрупкими к визуальным изменениям.

## Где используется

1. Запускается Vitest через `npm run test`.
2. Тестирует `src/components/Auth/RegisterForm.tsx`.
3. Использует общий test setup из `src/test/setup.ts`.
