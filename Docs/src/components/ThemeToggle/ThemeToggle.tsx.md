# src/components/ThemeToggle/ThemeToggle.tsx

## Что делает файл

Компонент отображает UI-переключатель темы и вызывает изменение темы через `theme.store`.
Визуально показывает текущее состояние (Sun/Moon), а также поддерживает вариант с поворотом для встраивания в разные места интерфейса.

## Импорты и зависимости

1. `react` (`useState`, `useEffect`) - локальный флаг загрузки компонента.
2. `lucide-react` (`Sun`, `Moon`) - иконки светлой и темной темы.
3. `src/store/theme.store.tsx` (`useThemeStore`) - чтение текущей темы и вызов переключения.

## Экспорты и контракты

1. Экспортируется default-компонент `ThemeToggle`.
2. Пропсы:
3. `rotate?: boolean` (по умолчанию `false`) - визуальный поворот кнопки/иконки для layout-сценариев.
4. Контракт поведения:
5. Клик по кнопке вызывает `toggleTheme` из store.
6. `aria-label` и `title` зависят от текущей темы (`isDark`).
7. Инварианты:
8. До установки `isLoaded` компонент ничего не рендерит.
9. После рендера источник состояния - только `theme.store`.

## Нетривиальная логика

1. `isLoaded` используется как hydration-safety механизм: компонент возвращает `null` до первого `useEffect`, чтобы избежать визуального рассинхрона темы на старте.
2. Логика анимации ползунка строится на классе `translate-x-*`, который зависит от `isDark`.
3. Для доступности добавлен скрытый текст (`sr-only`) с текущим состоянием темы.

## Где используется

1. `src/components/Header/Header.tsx` - desktop-вариант (`<ThemeToggle rotate={true} />`) и mobile-вариант (`<ThemeToggle />`).
2. Косвенно зависит от `src/store/theme.store.tsx`.
