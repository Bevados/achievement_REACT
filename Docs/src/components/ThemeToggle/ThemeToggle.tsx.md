# src/components/ThemeToggle/ThemeToggle.tsx

## Что делает файл

Компонент отображает переключатель темы и вызывает смену темы через `theme.store`.
Он показывает текущее состояние через иконки Sun/Moon и поддерживает опциональный поворот для разных мест в интерфейсе.

## Импорты и зависимости

1. `lucide-react` (`Sun`, `Moon`) поставляет иконки светлой и темной темы.
2. `src/store/theme.store.tsx` (`useThemeStore`) даёт текущее значение `isDark` и действие `toggleTheme`.

## Экспорты и контракты

1. Экспортируется default-компонент `ThemeToggle`.
2. Проп `rotate?: boolean` по умолчанию равен `false` и влияет только на визуальный поворот кнопки и ползунка.
3. Клик по кнопке вызывает `toggleTheme` из store.
4. `aria-label`, `title` и скрытый текст `sr-only` зависят от текущего значения `isDark`.
5. Источник состояния темы у компонента один: `theme.store`.

## Нетривиальная логика

1. Положение ползунка вычисляется через классы `translate-x-1` и `translate-x-8` в зависимости от `isDark`.
2. Если `rotate=true`, поворачивается и контейнер, и внутренняя иконка, чтобы компонент корректно выглядел в альтернативных layout-сценариях.
3. Для доступности добавлен скрытый текст `sr-only` с описанием текущей выбранной темы.

## Где используется

1. `src/components/Header/Header.tsx` - desktop-вариант (`<ThemeToggle rotate={true} />`) и mobile-вариант (`<ThemeToggle />`).
2. Косвенно зависит от `src/store/theme.store.tsx`, где хранится логика смены темы.
