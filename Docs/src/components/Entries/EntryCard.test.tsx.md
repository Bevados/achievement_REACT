# src/components/Entries/EntryCard.test.tsx

## Что делает файл

Файл тестирует UI-контракт базовой карточки `Entry`.
Покрывает обязательные поля, optional-поля и компактный рендер при минимальном наборе данных.

## Импорты и зависимости

1. `vitest` используется как тестовый раннер и assertion layer.
2. `@testing-library/react` рендерит компонент и ищет элементы в DOM.
3. `src/components/Entries/EntryCard.tsx` - тестируемый компонент.
4. `contracts/collection.contracts.ts` дает тип `EntryView` для тестовых данных.

## Экспорты и контракты

1. Runtime-экспортов нет.
2. Проверяемые контракты:
2.1. обязательные поля `title` и `status` всегда видны;
2.2. action-кнопки-заглушки существуют и disabled;
2.3. optional-поля рендерятся только при наличии;
2.4. минимальная карточка не показывает пустые блоки цены, оценки и изображения.

## Нетривиальная логика

1. Тест на optional-поля одновременно проверяет и медиа, и метаданные, и tags, чтобы зафиксировать полный expanded-state карточки.
2. Тест на compact-state защищает от регрессии, когда UI случайно начнет рендерить пустые подписи `Цена`, `Оценка` или broken image block.

## Где используется

1. Запускается в наборе `npm run test`.
2. Защищает от регрессий `src/components/Entries/EntryCard.tsx`.
