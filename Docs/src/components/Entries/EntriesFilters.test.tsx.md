# src/components/Entries/EntriesFilters.test.tsx

## Что делает файл

Тестирует поведение панели фильтров карточек.

## Импорты и зависимости

1. `vitest` — тестовые сценарии и моки callbacks.
2. `@testing-library/react` — рендер и поиск элементов.
3. `@testing-library/user-event` — клики по toggle и action-кнопкам.
4. `./EntriesFilters` — тестируемый компонент панели фильтров.

## Экспорты и контракты

1. Файл ничего не экспортирует.
2. Покрывает UI-контракт панели:
   - collapsed-состояние по умолчанию;
   - переключение `aria-expanded`;
   - сохранение основных групп полей после раскрытия;
   - вызовы `onApply` и `onReset`.

## Что проверяется

1. Стартовое collapsed-состояние.
2. Переключение `aria-expanded` при открытии и закрытии.
3. Наличие основных групп полей после раскрытия.
4. Вызов `onApply`.
5. Вызов `onReset`.

## Нетривиальная логика

1. После добавления плавной анимации контент панели больше не удаляется из DOM при сворачивании, поэтому тесты опираются на `aria-expanded`, а не на полное исчезновение элементов.
2. Сценарии проверяют именно пользовательский toggle-flow, а не внутреннюю реализацию анимации.

## Где используется

1. Запускается через `npm.cmd run test`.
