# src/components/Entries/EntriesFilters.test.tsx

## Что делает файл

Файл тестирует общий UI-контракт `EntriesFilters`.
Покрывает открытие/закрытие панели фильтров и вызовы `onApply` / `onReset`.

## Импорты и зависимости

1. `vitest` — тестовый раннер и assertions.
2. `@testing-library/react` — рендер и поиск элементов.
3. `@testing-library/user-event` — имитация действий пользователя.
4. `./EntriesFilters` — тестируемый компонент.

## Экспорты и контракты

1. Runtime-экспортов нет.
2. Проверяемые контракты:
   - панель фильтров по умолчанию свернута;
   - кнопка раскрывает и скрывает все группы фильтров;
   - submit вызывает `onApply`;
   - кнопка сброса вызывает `onReset`.

## Нетривиальная логика

1. Тесты работают на уровне контракта формы, а не внутреннего state-management detail-страниц: важно зафиксировать, что общий UI фильтров остается переиспользуемым и не зависит от конкретного fetcher-а.

## Где используется

1. Запускается через `npm run test`.
2. Защищает от регрессий `src/components/Entries/EntriesFilters.tsx`.
