# src/components/Collections/CollectionCard.test.tsx

## Что делает файл

Файл проверяет корректный рендер карточки коллекции.
Покрывает основной сценарий отображения данных и fallback-сценарий отсутствующих optional-полей.

## Импорты и зависимости

1. `vitest` - тестовый раннер и ассерты.
2. `@testing-library/react` - рендер компонента и поиск элементов.
3. `src/components/Collections/CollectionCard.tsx` - тестируемый компонент.
4. `contracts/collection.contracts.ts` - типизация тестовых данных (`CollectionView`).

## Экспорты и контракты

1. Файл не экспортирует production-сущности.
2. Содержит unit-тесты UI-контракта карточки.

## Нетривиальная логика

1. Проверяется отображение категории, количества карточек, публичного бейджа и даты обновления.
2. Проверяется корректный fallback при отсутствии `description` и `coverImageUrl`.

## Где используется

1. Запускается Vitest-командой проекта (`npm test`).
2. Закрывает минимальное требование шага по корректному рендеру карточки коллекции.
