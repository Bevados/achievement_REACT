# src/components/Collections/CollectionForm.test.tsx

## Что делает файл

Тестирует UI-контракт `CollectionForm` без backend-submit.
Покрывает create/edit режимы, локальное редактирование полей, кнопку `Отмена` и disabled-состояние кнопки сохранения.

## Импорты и зависимости

1. `vitest` — тестовый раннер и моки.
2. `@testing-library/react` — рендер и проверки DOM.
3. `@testing-library/user-event` — интерактивное изменение полей и клик по кнопкам.
4. `./CollectionForm` — тестируемый компонент.

## Экспорты и контракты

1. Runtime-экспортов нет.
2. Проверяемые инварианты:
   - create-форма стартует пустой;
   - edit-форма подставляет initial values;
   - поля реально меняют локальный state;
   - `Отмена` вызывает callback;
   - `Сохранить` остаётся disabled на шаге 5.4.

## Нетривиальная логика

1. Тест не пытается эмулировать реальный submit, потому что это осознанно следующий подпункт плана.
2. Проверка helper-текста защищает от регрессии, при которой пользователь видит disabled-кнопку без объяснения причин.

## Где используется

1. Запускается в `npm.cmd run test`.
2. Страхует `src/components/Collections/CollectionForm.tsx` от регрессий перед подключением react-hook-form и Zod.
