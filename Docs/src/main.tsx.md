# src/main.tsx

## Что делает файл

Это точка входа frontend-приложения.
Файл монтирует React-приложение в DOM-элемент `#root`, подключает роутинг (`BrowserRouter`) и включает `StrictMode` для разработки.

## Импорты и зависимости

1. `react` (`StrictMode`) - дополнительная проверка потенциальных side-effect проблем в режиме разработки.
2. `react-dom/client` (`createRoot`) - современный API рендера React 18+.
3. `react-router-dom` (`BrowserRouter`) - включает клиентскую маршрутизацию.
4. `src/index.css` - глобальные стили приложения.
5. `src/App.tsx` - корневой компонент интерфейса.

## Экспорты и контракты

1. Файл ничего не экспортирует.
2. Контракт файла - побочный эффект запуска приложения при загрузке модуля.
3. Инварианты:
4. В `index.html` должен существовать элемент с id `root`.
5. `BrowserRouter` оборачивает весь `App`, чтобы `Link`/`useLocation` работали в любом дочернем компоненте.

## Нетривиальная логика

1. Нетривиальной бизнес-логики здесь нет; файл intentionally минимальный.
2. Ключевое архитектурное решение - провайдер роутера находится на самом верхнем уровне, чтобы не дублировать его в отдельных страницах/компонентах.

## Где используется

1. Загружается Vite автоматически как entrypoint frontend-части.
2. Косвенно запускает весь UI-слой через рендер `src/App.tsx`.
