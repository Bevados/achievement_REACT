# scripts/seed-system-examples.mjs

## Что делает файл

Скрипт заполняет MongoDB системными demo-данными для публичного examples-потока.
Создает коллекции и карточки с `ownerId=system_examples`, выставляет `isPublic=true` и синхронизирует `entriesCount`.

## Импорты и зависимости

1. `dotenv` - загрузка `MONGODB_URI` из `.env.local`/`.env`.
2. `mongodb` (`MongoClient`, `ObjectId`) - прямой доступ к БД и генерация идентификаторов.

## Экспорты и контракты

1. Файл не экспортирует production-сущности.
2. Запуск выполняется через npm-скрипт:
   - `npm run seed:examples` (запись в БД),
   - `npm run seed:examples -- --dry-run` (проверка без записи).

## Нетривиальная логика

1. Перед вставкой очищаются старые `system_examples` данные (`collections` + `entries`) для идемпотентного повторного запуска.
2. Генерируется 18 коллекций для проверки пагинации списка.
3. Для первой коллекции генерируются все 64 комбинации optional-полей entry (`description/imageUrl/priceCents/tags/rating/date`).
4. Для остальных коллекций генерируются данные с вариативными optional-полями и количеством карточек выше порога пагинации.
5. После вставки entries выполняется bulk-обновление `entriesCount` у коллекций.

## Где используется

1. Локальный dev seed для наполнения examples-данными.
2. Smoke/ручные проверки UI сценариев с реальным API и реальной БД.
